## 1. GET /api/text

Возвращает простой текстовый ответ.

* **Метод:** `GET`
* **URL:** `/api/text`
* **Параметры:** отсутствуют
* **Код ответа:** `200 OK`
* **Заголовки (Headers):** `Content-Type: text/plain; charset=utf-8`

### Пример запроса
```http
GET /api/text HTTP/1.1
Host: localhost:1880
```

### Пример ответа
```text
Привет! Это простой текстовый ответ от сервера Node-RED.
```

## 3. GET /api/items/:id

Эндпоинт для получения информации о конкретном товаре по идентификатору. Использует путь с параметром (path parameter) `:id`.

* **Метод:** `GET`
* **URL:** `/api/items/:id`
* **Параметры пути (Path params):**
  * `id` *(число)* — идентификатор запрашиваемого объекта. В тестовой базе доступны значения: `1`, `2`, `3`.

---

### 3.1. Успешный запрос (200 OK)

Вызывается, если передан существующий числовой идентификатор.

* **Запрос:** `GET /api/items/1`
* **Код ответа:** `200 OK`
* **Заголовки:** `Content-Type: application/json; charset=utf-8`
* **Тело ответа:**
```json
{
  "id": 1,
  "name": "Ноутбук",
  "category": "electronics"
}
```

---

### 3.2. Ошибка: Объект не найден (404 Not Found)

Вызывается, если передан числовой идентификатор, которого нет в базе данных.

* **Запрос:** `GET /api/items/99`
* **Код ответа:** `404 Not Found`
* **Заголовки:** `Content-Type: application/json; charset=utf-8`
* **Тело ответа:**
```json
{
  "error": "Not Found",
  "message": "Элемент с id=99 не найден"
}
```

---

### 3.3. Ошибка: Некорректный запрос (400 Bad Request)

Вызывается, если в качестве идентификатора передана строка вместо числа.

* **Запрос:** `GET /api/items/abc`
* **Код ответа:** `400 Bad Request`
* **Заголовки:** `Content-Type: application/json; charset=utf-8`
* **Тело ответа:**
```json
{
  "error": "Bad Request",
  "message": "Параметр id должен быть числом"
}
```
