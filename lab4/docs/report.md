## 1. Краткое описание выполненного
В рамках лабораторной работы была развернута платформа автоматизации n8n вместе с базой данных Redis в контейнерах Docker с монтированием локальных томов (volumes). Были изучены базовые и расширенные узлы n8n, построены цепочки автоматизации с ручным запуском, модификацией полей, написанием кода на JavaScript, ветвлением логики, выполнением внешних HTTP-запросов к публичному API и периодическим запуском по расписанию. Также настроена интеграция с Redis, в которой продемонстрирован полный жизненный цикл ключа: создание, чтение значения, удаление и верификация отсутствия. Все сценарии сохранены в формате JSON в директорию `flows/`.

## 2. Использованные AI-промпты
1. **Конфигурация Docker Compose:**
   > «Сформируй конфигурацию docker-compose.yml для одновременного запуска n8n и Redis с монтированием томов для сохранения данных и пробросом портов 5678 и 6379.»
2. **Логика для JavaScript-ноды Code:**
   > «Напиши код для ноды Code в n8n с использованием let/const, if/else, цикла for, массива и объекта с возвратом объекта с полем payload.»
3. **HTTP-запрос к публичному API:**
   > «Сгенерируй JSON-схему для воркфлоу n8n с выполнением GET-запроса к открытому API случайных цитат/шуток с парсингом ответа в ноде Code.»

## 3. Освоенные ноды n8n
- **Manual Trigger:** ручной запуск сценария для тестирования и отладки цепочки.
- **Edit Fields (Set):** создание, перезапись и форматирование полей структуры данных (`topic`, `timestamp`, `payload`).
- **Code:** реализация кастомных вычислений и трансформаций на чистом JavaScript (ES6+).
- **IF:** условное ветвление сценария на потоки True / False в зависимости от значений в объекте.
- **HTTP Request:** выполнение сетевых запросов (GET) к внешним REST API без авторизации и парсинг полученного JSON.
- **Schedule Trigger:** запуск воркфлоу по расписанию (интервал времени).
- **Redis:** подключение и выполнение операций с БД типа ключ-значение (Set, Get, Delete).
