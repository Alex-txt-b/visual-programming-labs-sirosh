# Процесс заказа еды в ресторане с доставкой

**Участники:** Клиент, Сайт (Система), Кухня, Курьер.

**Описание процесса:**
1. Клиент выбирает блюда в приложении.
2. Клиент переходит к оформлению заказа.
3. Система проверяет адрес доставки.
4. Клиент выбирает метод оплаты.
5. Система обрабатывает платеж.
6. Если оплата успешна, заказ передается на кухню.
7. Кухня начинает готовить блюда.
8. (Параллельное действие) В это же время система ищет свободного курьера.
9. Курьер принимает заказ.
10. Кухня упаковывает готовые блюда.
11. Курьер забирает заказ из ресторана.
12. Курьер доставляет еду клиенту.
13. Клиент получает заказ.

**Условия ветвления:**
* Проверка адреса: доступна ли доставка в данный район?
* Оплата: прошла ли транзакция успешно?
