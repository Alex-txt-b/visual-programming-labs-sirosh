# Отчет по лабораторной работе №1
## Цель работы: 
Настроить Git-репозиторий, освоить базовые команды и работу 
с графическими нотациями (BPMN, UML Activity, Sequence, Flowchart), 
сохранить все артефакты в репозитории и на практике увидеть разницу между 
текстовыми и бинарными форматами при версионировании. 
## 1. Описание процесса
Процесс «Заказ еды в ресторане с доставкой» включает взаимодействие Клиента, Системы, Кухни и Курьера. Основной поток: выбор блюд, оформление, оплата, приготовление и доставка. Предусмотрены сценарии ошибок (недоступность адреса, ошибка оплаты).

## 3. Вывод
Git в связке с GitHub — это мощный инструмент, который упрощает обмен кодом и позволяет контролировать проект на каждом этапе разработки, в том числе с помощью системы коммитов. На практике я наглядно увидел существенные различия между текстовыми и бинарными форматами при версионировании. Хотя бинарные форматы (например, PNG) удобны для отчетов, они проигрывают текстовым форматам, так как в последних можно детально отслеживать историю изменений (diff). Это делает текстовые форматы незаменимыми для профессиональной разработки и полноценного версионирования проектов.
